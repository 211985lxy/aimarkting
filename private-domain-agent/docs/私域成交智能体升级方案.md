# 李相宇私域成交智能体升级方案

## 目标

把微信私域从“靠人盯、靠感觉聊”升级成一套半自动成交系统：

1. 发现线索：朋友圈、群聊、私聊里谁对AI、内容、获客、企业IP有需求。
2. 理解客户：回顾聊天上下文，判断客户所处阶段和真实痛点。
3. 生成跟进：给出符合李相宇人设的话术，不油、不装、不焦虑。
4. 人工确认：所有对外发送都必须由本人确认。
5. 形成复盘：每天沉淀高意向客户、常见问题、成交阻力、内容选题。

## 当前已可用

### 1. 客户跟进话术

命令：

```bash
python3 /Users/xiangyu/Desktop/明动aim智能体/private-domain-agent/scripts/private_domain_agent.py draft \
  --scenario "365社群新成员欢迎" \
  --customer "刚成交的新成员" \
  --need "想学习AI商业变现，但比较小白"
```

适用：

- 新成员欢迎
- 成交后交付引导
- 私聊客户追问
- 低意向客户轻激活
- 高意向客户预约咨询

### 2. 单联系人确认后发送

已接入 `wechat-personal-message`，环境检查通过。

安全规则：

- 默认只展示消息，不发送。
- 只有明确带 `--confirm-send` 才会执行发送。
- 不做批量群发，不做自动轰炸。

## 已拉到本地的候选仓库

### WeChat-MCP

位置：

`private-domain-agent/repos/WeChat-MCP`

能力：

- 读取指定联系人/群的最近消息。
- 给指定联系人/群发送回复。
- 添加微信联系人。
- 发布纯文字朋友圈，可只生成草稿不发布。

适合放在主链路：

客户跟进前，先读取最近聊天记录，然后生成跟进建议，再由你确认发送。

建议级别：高。

### wx-cli

位置：

`private-domain-agent/repos/wx-cli`

能力：

- 查最近会话。
- 搜索微信聊天历史。
- 查看联系人、群成员、未读消息。
- 查询本地缓存的朋友圈。
- 查询公众号文章、收藏等。

适合放在情报层：

对客户做“成交前背景回顾”，比如他之前问过什么、是否提过预算、是否关注企业IP/AI/短视频。

风险：

- 首次初始化需要读取本地微信数据库，配置复杂。
- 涉及本地隐私数据，必须只在本人电脑使用。

建议级别：高，但需要谨慎配置。

### wechat-macos-proxy

位置：

`private-domain-agent/repos/wechat-macos-proxy`

能力：

- 发送消息。
- 读取聊天截图。
- 导出聊天记录。
- 批量发送。

适合做备用执行层。

风险：

- 依赖 `peekaboo` 和 `jq`。
- 批量发送能力容易带来微信风控和私域信任损耗。

建议级别：中。只用单发/读取/导出，不启用批量群发。

## 推荐系统架构

```text
客户动态/聊天记录
        ↓
wx-cli / WeChat-MCP 读取上下文
        ↓
私域成交智能体判断客户阶段
        ↓
生成 2-3 版跟进话术
        ↓
李相宇人工确认
        ↓
wechat-personal-message / WeChat-MCP 单条发送
        ↓
每日复盘：高意向客户、成交阻力、内容选题
```

## 每天成交一个客户的私域动作

### 上午：线索盘点

输出三张表：

- 今日高意向客户：主动问AI、问社群、问资料、问价格的人。
- 今日可激活客户：点赞、评论、看过资料但没行动的人。
- 今日内容选题：客户反复问的问题。

### 下午：私聊推进

每个客户只做一个动作：

- 小白：发资料和自测问题。
- 有业务：问他现在的产品、客单价、获客渠道。
- 有团队：引导到“AI短视频市场部”诊断。
- 已成交：给交付路径和第一步任务。

### 晚上：群内信任建设

发三类内容：

- 一个真实客户问题。
- 一个AI商业变现拆解。
- 一个可执行的小作业。

## 下一步建议

1. 先接 `WeChat-MCP`，做“读取最近聊天 + 生成跟进草稿”。
2. 再接 `wx-cli`，做“聊天历史搜索 + 客户画像”。
3. 朋友圈雷达后续自己补采集模块，不再依赖当前残缺仓库。
4. 如果要群自动发内容，优先迁移到企微/飞书机器人，不建议个人微信直接群发。
