# 李相宇命理档案

## 基础信息

```text
男命
丁丑年 壬子月 甲申日 乙亥时
出生地：河南濮阳范县
问事地：杭州
```

核心判断：

```text
甲木日主，水多木漂，身弱寒湿。
喜火土，忌水泛。
财官杀来有机会，也有压力。
```

这个盘不是享福躺赢型，而是创业折腾型、项目压力型、后运改善型。机会不缺，但大多要通过压力、项目、客户、合作和风险控制来兑现。

## 命局定性

### 八字

- 甲木生子月，壬子、乙亥、水势重，寒湿明显。
- 原局印旺、水旺，容易想法多、内耗多、方向漂。
- 不是身旺担财官的盘，财官杀来时机会和压力同时出现。
- 第一用火：表达、销售、品牌、曝光、产品化、行动力。
- 第二用土：现金流、合同、交付、组织、资产、稳定客户。
- 金可借规则和平台，但不能被官杀压力压死。
- 水不宜再增，少泡在人情、信息、犹豫和无结果的学习里。

### 紫微

按四柱反推紫微盘口径：

```text
1997-12-08 亥时 男命
命宫：太阳、太阴，太阴化禄
官禄：天梁陷，带陀罗
财帛：空宫，天钺、铃星
福德：天机化科、巨门化忌
```

紫微定性：

- 命宫有财感和资源感，不是低盘。
- 官禄天梁陷、陀罗，事业路慢、责任重、卡点多。
- 财帛空宫带天钺、铃星，有贵人和机会，但财运波动。
- 福德巨门化忌，思虑重，容易焦虑、怀疑、内耗。
- 中年破军大限，事业会有重组、换模式、业务线改造。

### 奇门

杭州问事局事业取象：

```text
开门、值符、天心落乾宫
生门落艮宫
乙落震宫，伤门、天冲、六合
景门落离宫但空
死门落坤宫
```

奇门定性：

- 有事业门：适合正规平台、大客户、专业能力、项目管理、系统化服务。
- 有财门：财在长期客户、稳定项目、暗资源、资产沉淀。
- 本人急，合作易伤，不能靠临时冲劲和口头承诺。
- 宣传曝光可以做，但要防“声量大于转化”。

## 合作与婚姻事业结构

这个命最拧巴的点：

```text
不能纯单打独斗。
也不能深度绑定合伙。
```

最佳模式：

```text
主控型协作
```

也就是：

- 他掌方向、客户、成交、关键判断。
- 别人做交付、运营、财务、执行模块。
- 可以分利润，不能乱分权。
- 可以合作，不能共命。
- 可以用人，不能被人绑。

### 若老婆是假从杀

老婆若是假从杀，则属于压力型助力。

```text
能帮他定规矩、推执行、管风控。
也容易压他、控制他、让家庭像公司。
```

适合夫妻协作，不适合夫妻共权。

最佳分工：

```text
他：方向、资源、客户、产品、对外关系
她：流程、财务、监督、执行、风控、内部管理
```

禁忌：

- 夫妻五五共权但没有最终拍板人。
- 家事公事混在一起。
- 钱不分账。
- 用婚姻身份管公司。
- 用老板身份压老婆。

## 用命方式

核心口诀：

```text
用火土，不碰水坑，借规则，不硬扛官杀。
```

实际打法：

1. 用火：表达、销售、品牌、曝光、产品化。
2. 用土：现金流、合同、交付、资产、稳定客户。
3. 借金：规则、平台、大客户、资质、合同。
4. 避水：拖延、人情、内耗、信息过载、无结果学习。

最适合事业模型：

```text
专业能力 + 商业表达 + 标准交付 + 长期客户
```

适合方向：

- 项目制服务
- 咨询/顾问
- 技术产品化
- 教育培训
- 企业服务
- 资源整合
- 供应链/实体项目
- 大客户长期合作

必须补齐三套系统：

```text
销售系统
交付系统
财务系统
```
