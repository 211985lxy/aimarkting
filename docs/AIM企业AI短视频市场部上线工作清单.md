# AIM企业AI短视频市场部上线工作清单

## 一、上线目标

7 天内跑通第一版交付闭环：

> 客户资料采集 → AIM 知识库入库 → 生成选题/脚本/拍摄交接单 → 审核发布 → 数据回填 → 周复盘。

第一版先服务两个对象：

- 李相宇自己的账号
- 第一个付费客户或种子客户

## 二、产品收束

### 1. 产品名

**AIM企业AI短视频市场部搭建系统**

### 2. 一句话定位

帮传统企业把老板经验、产品卖点和客户信任，搭成一套可持续获客的 AI 短视频市场部。

### 3. 产品阶梯

| 产品 | 定位 | 建议价格 |
|---|---|---|
| 365社群 | 轻交付、引流、日常陪跑 | 365元/年 |
| 7天搭建营 | 搭出第一个 AI 内容闭环 | 1999-2999元 |
| 企业陪跑 | 跑通短视频获客系统 | 9800-19800元 |
| 定制搭建 | 企业 AI 短视频市场部定制交付 | 3万+ |

## 四、AIM 后台最小可用范围

第一版只保证 5 个核心页面能用：

- [ ] 企业知识库：录入老板经验、产品卖点、客户痛点、项目案例、客户问答。
- [ ] IP 档案：建立商业定位、人设定位、内容定位。
- [ ] AIM 内容生成：生成视频脚本、朋友圈、公众号、拍摄交接单。
- [ ] 质量检测：检测 AI 味、吸引力、逻辑和表达质量。

## 七、员工每日 SOP

员工每天只做 6 件事：

1. 收集客户资料。
2. 录入 AIM 知识库。
3. 生成选题、脚本或拍摄交接单。
4. 发给李相宇或客户审核。
5. 整理拍摄交接单。
6. 发布后回填数据。

员工不负责战略判断，只负责按系统执行。
